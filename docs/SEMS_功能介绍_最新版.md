## P1 — 封面

**SEMS 半导体设备管理系统**
Semiconductor Equipment Management System

- 面向半导体制造车间的轻量级设备管理平台
- FastAPI + Vue 3 · 零配置 SQLite 开箱即用
- 版本：V2026.08（2026-08 更新）

---

## P2 — 整体定位

**为什么需要 SEMS？**

- 晶名半导体设备部门痛点：
  - 设备状态靠电话/微信群，台账分散在 Excel/纸档
  - 故障处置经验沉淀差，同一根因反复复发
  - 点检/PM/润滑执行难追踪，容易漏做
  - 备件库存不透明，等要修了才发现缺件
  - 工艺文件版本与审批靠邮件，追溯困难
  - 8D 报告写完就丢，知识库与品管工具完全脱节

**一句话价值**：把设备台账、日常运维、工艺文控、品管合规、数据价值**五个核心闭环**落在一套系统里，真正"数据可查、经验可复用"。

## P3 — 五大业务闭环

| 闭环 | 覆盖模块 | 业务价值 |
|------|---------|---------|
| **① 设备台账 & 状态闭环** | 设备台账 / 状态切换 / 设备全生命周期 T0-T3 / 润滑管理 | 机台状态一眼看清，DOWN 自动派工单 |
| **② 日常运维闭环** | 工单 / PM 计划 / 点检巡检 / 备件管理 / 工单 SLA 升级 | 从建单→维修→验证→关单一气呵成，超时自动升级 |
| **③ 工艺文控闭环** | 工艺文件 / 表单模板 / 电子表单 / 文控审批链（三级签名）/ 分发收回 / 复审告警 | 符合体系标准的受控文控，水印+指纹+留痕 |
| **④ 品管合规闭环** | 8D / FMEA / 安全检查（装置/特种设备/证书/整改）/ 环境核查 | 质量分析合规可追溯，证书到期提前告警 |
| **⑤ 数据价值闭环** | **故障知识库（工单归档 + 8D 归档 + 相似案例 + 复发追踪）** / OEE / 设备成本 LCC | 故障经验不随人流失，LCC 一眼算清单台成本 |

## P4 — V2026.08 版本核心更新（重点！）

**📚 8D 报告 → 故障知识库 一键归档（双路径沉淀）**
- D0(问题描述) + D2(问题定义) → 故障现象
- D4(根因) → 根因 / D5(永久措施) → 处置 / D7(预防) → 预防
- 自动关联 `source_d8_report_id` 溯源 + 关联工单 ID
- 同时保留「工单归档」入口：工单一键也能变知识

**📋 8 大分组分级菜单**
- ① 设备管理 ② 日常运维 ③ 工艺文控 ④ 品管工具 ⑤ 合规安全 ⑥ 数据价值 ⑦ 人员资产 ⑧ **系统配置（永远在最下方）**
- 展开/收起式折叠导航，不再一级平铺

**🎯 角色定制看板**
- 6 种角色（admin/engineer/process/qa/operator/viewer）登录→不同看板卡片组合与排序
- QA 优先：文控复审告警 + 8D 进度 / 操作员优先：今日点检 + 设备状态

**🧾 敏感操作审计日志入库**
- LOGIN_OK/FAIL/LOCKED、PASSWORD_CHANGED、USER_CREATE/UPDATE/DELETE/UNLOCK、LOGOUT、RESTORE_BACKUP
- 写入 `audit_logs` 表（操作人/目标/IP/UA/时间戳/详情），满足体系审核留痕

**🔐 密码 bcrypt 72 字节截断安全修复**
- SHA-256 预哈希 → bcrypt 二次哈希；旧值透明回退 + 登录成功自动升级重哈希

## P6 — ① 设备管理 & DOWN→工单自动派发

**设备台账**
- 厂区/区域分类、附件上传（说明书/图纸/SOP）、关联易损件清单、状态历史追溯

**状态切换 ⇢ 工单自动派发**
- 任意角色切 `DOWN` → 自动创建 `REPAIR` 工单（含故障现象+紧急度）→ 自动派工程师
- 状态：RUN / IDLE / DOWN / PM / ENGINEERING / PROCESS_VALIDATION / OFFLINE

**设备全生命周期 T0-T3**
- T0 选型（URS/候选供应商）→ T1 采购（PO/金额/交付）→ T2 安装调试（FAT/SAT/Commissioning）→ T3 量产移交（验收结果）
- 时间线视图一眼看全流程进度

**润滑管理（五定）**
- 定点（点名称/位置）/ 定人（责任人）/ 定时（频次/周期）/ 定质（油品/等级）/ 定量（用量/单位）
- 自动推算下次润滑日，到期提醒高亮

## P7 — ② 日常运维闭环 & 工单 SLA

**工单管理**
- 创建/跟踪、紧急度标签、持续时长实时显示、关键词全文检索
- 详情：5Why 根因分析 + 备件领用 + 状态流转（OPEN→IN_PROGRESS→PENDING_VERIFY→CLOSED/CANCELLED）

**SLA & 超时升级**
- SLA 目标响应时长 / 解决时长（按紧急度预设）
- 实际响应/解决时长自动计算 → SLA 达成率统计
- 超时自动升级指派更高级别工程师

**PM 维护计划 / 点检巡检 / 备件管理**
- PM：周/双周/月/季 周期，批量生成到期 PM 工单
- 点检：模板+检查项+历史记录，设备 DOWN 后可追溯点检执行情况
- 备件：库存/出入库/低库存告警 / 设备易损件绑定

## P8 — ③ 工艺文控闭环

**工艺文件：指导性文件 + 作业记录双 Tab**
- 指导性文件：Recipe/流程图/规格书/SOP，版本管理，生效版唯一，同组旧版自动作废

**结构化电子表单（替代 PDF）**
- 管理员定义模板：9 种字段类型（text/textarea/number/select/radio/date/datetime/time/boolean）
- 操作员：工艺文件→新建电子表单→选模板→动态渲染→填写→保存草稿/提交→自动归档
- 数据结构化存储，JSON/CSV 导出

**文控系统（符合体系标准）**
- 三级电子签名审批链：编制→审核→批准（需二次密码校验 → SHA256 签名指纹）
- 状态机白名单：草稿↔审核中→生效→作废（单向不可逆）
- 修订记录：字段级 before/after 对比
- 分发收回台账、PDF 下载自动加盖**受控章水印**（编号+状态+下载人+日期）
- 表单审核锁定 + 附加修正（审核后禁止原地修改，走修正审批流程）
- 复审周期告警：按 `next_review_date` 30 天内/已过期红色 Badge

## P9 — ④ 品管合规闭环

### 8D 报告

8 个步骤完整建模：
- D1 组建团队 → D2 问题定义 → D3 临时遏制 → D4 根因分析 → D5 永久措施 → D6 验证 → D7 预防再发 → D8 表彰总结
- 关联工单（可选）、状态：DRAFT / IN_PROGRESS / CLOSED
- **⭐ 已关闭报告一键「归档知识库」**：D0+D2→现象 / D4→根因 / D5→处置 / D7→预防，自动建知识条目，经验沉淀

### FMEA
- 失效模式 / 影响 / 严重度(S 1-10) / 频度(O) / 探测度(D)
- 自动算 RPN = S×O×D，RPN>100 高亮

### 安全检查（四类）
- safety_device 安全装置（防护罩/急停/联锁）/ special_equipment 特种设备 / environmental 环保 / fire_protection 消防
- 按频率自动推算下次检查日，30 天内黄底、已过期红字
- 特种设备证书到期 Badge，检查发现 / 整改措施跟踪

### 环境核查
- 温度/湿度/洁净度/VOC/ESD 电压等参数录入与趋势

## P10 — ⑤ 数据价值闭环

### ⭐ 故障知识库（双路径归档 + 相似案例 + 复发追踪）

**双路径沉淀**
| 来源 | 入口 | 自动映射 |
|------|------|---------|
| 工单 | 知识库→「从工单归档」 | description→现象 / fault_category→分类 / root_cause→根因 / solution→处置 / prevention→预防 |
| **8D 报告** | 知识库→「从 8D 报告归档」或 8D 列表→「归档至知识库」 | D0+D2→现象 / D4→根因 / D5→处置 / D7→预防 |
| 手动 | 新建条目 | 任意填写 |

**相似案例推荐**
- 同设备 + 同故障分类 优先 → 同设备或同分类 退化
- 按复发次数/浏览量倒序，新故障一眼看到以前怎么修的

**复发追踪**
- 同一根因复发 → 点「标记复发」→ recurrence_count +1
- 看板/列表一眼看出哪些根因反复出现、需要重点改进

## P12 — 安全 & 审计 & 灾备

### 安全加固（面向局域网部署）
- 身份：JWT 双令牌（2h access + 7d refresh，5 分钟前自动续期）/ bcrypt(SHA-256 预哈希，修复 72 字节截断)/ 密码 3/4 类字符复杂度 / 失败锁定 5 次/15min / 首次登录强制改密 / 用户名枚举防护
- 传输：CORS 收紧 + CSP / X-Frame / X-Content-Type-Options / Referrer-Policy / Permissions-Policy

### 🧾 审计日志入库（审核留痕）
- 11 类动作全入库：LOGIN_OK / LOGIN_FAIL / LOGIN_LOCKED / LOGOUT / PASSWORD_CHANGED / PASSWORD_RESET / USER_CREATE / USER_UPDATE / USER_DELETE / USER_UNLOCK / RESTORE_BACKUP
- 每条含：action / actor / target / ip / user_agent / detail / created_at

### 灾备（3-2-1 策略）
- 应用内定时备份 + SQLite 热快照 + ZIP + AES-256(Fernet/PBKDF2 20万轮) + NAS/SMB/U盘异地副本
- 系统级旁路备份脚本（sh/bat，不依赖后端进程也能跑）
- **备份后自动烟雾还原测试**：解压→打开 sqlite→查表行数→校验 uploads，永远知道备份能不能真还原

## P13 — 部署方案选型

| 场景 | 推荐部署 | 自启 | 崩溃重启 | 健康检查兜底 |
|------|---------|------|---------|---------|
| 工厂 Linux 服务器有 root | **systemd（方案 A）** | ✅开机自启 | ✅on-failure | ✅cron 2min→重启 |
| 普通用户 / 受限 Linux | **watchdog_user.sh（方案 B）** | ✅@reboot | ✅每分钟 tick→拉起 | ✅同上 |
| Windows Server / 工控机 | **NSSM + 任务计划（方案 C）** | ✅延迟自启 | ✅NSSM + SC failure | ✅2min 计划任务 |
| 容器化 / 快速体验 | **Docker Compose（方案 D）** | ✅unless-stopped | ✅compose restart | ✅healthcheck |

**入口级加固（开箱即用）**
- 端口占用友好提示（exit=2，避免 systemd 无限重启）
- SQLite WAL checkpoint 钩子（启动前 / 停服前各一次，降低损坏概率）
- uvicorn 优雅退出（keep_alive=75s / graceful_shutdown=30s）
- 日志双写：journald/NSSM 文件 + TimedRotatingFileHandler 按天滚动（14 天 sems.log / 30 天 sems.error.log）

## P15 — 技术栈 & 扩展路线

**当前技术栈**
- 后端：Python 3.10+ / FastAPI / SQLAlchemy 2.0 / SQLite（默认，零配置）
- 前端：Vue 3 / Vite / Element Plus / ECharts / Pinia
- 安全：JWT / bcrypt(+SHA256 prehash) / CSP+X-Frame 响应头 / CORS 白名单 / bcrypt 72 字节截断修复
- 备份：SQLite hot backup / ZIP / Fernet AES-256 / cron & 系统级旁路脚本
- 打包：Docker Compose / Linux systemd / Windows NSSM / PyInstaller

**短期扩展路线（Q4 规划）**
- ① 审计日志前端界面化（查询/导出 CSV）
- ② 知识条目审核流（草稿→QA 审核→生效）
- ③ 8D 报告通知（钉钉/飞书 Webhook）
- ④ 备品低库存自动建采购申请单

**中期扩展**
- 对接 MES：设备状态 / 工艺参数自动上传，减少人工录入
- 对接 SCADA：关键机台参数趋势、阈值报警
- 移动端（微信小程序/钉钉微应用）：点检 / 工单处理 / 扫码
