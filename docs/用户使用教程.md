## 1. 登录与密码

### 1.1 登录

1. 浏览器打开系统地址（如 `http://localhost:5173` 开发环境或 `http://<服务器IP>:8080` 生产环境）。
2. 输入用户名和密码，点击登录。

### 1.2 首次登录强制改密

- 系统默认管理员账号为 `admin` / `admin123`。
- 首次登录时系统会**强制跳转到修改密码页面**。
- 密码要求：
  - 至少 **8** 位
  - 包含大写字母、小写字母、数字、特殊符号中的 **至少 3 类**
  - 不能使用常见弱密码（如 `12345678`、`password`）

### 1.3 忘记密码

联系管理员重置密码。管理员重置后，您的账号会被标记为"必须改密"，下次登录时需重新设置密码。

### 1.4 登录过期

- 访问令牌有效期为 **2 小时**，系统会在到期前 5 分钟自动续期。
- 如果长时间不操作导致登录过期，系统会跳回登录页。重新登录即可。
- **如果反复提示"登录已过期"**：请清除浏览器 localStorage（F12 → Application → Local Storage → 删除 `sems_` 前缀的条目），然后重新登录。

## 2. 主题切换（明色青绿 / 暗色霓虹 / 跟随系统）

SEMS 内置两套配色方案，一套清爽一明一暗，并能一键跟随操作系统（Windows/macOS 浅/深）自动切换，长时间使用看板更护眼。

### 2.1 在哪里切换

登录进入主界面后，**右上角顶栏**有主题按钮（图标：太阳/月亮/显示器），显示当前使用的模式名称：

| 显示 | 含义 |
|------|------|
| 🌞 明色青绿 | 始终使用「极简青绿 B 方案」——适合白天、明亮办公室 |
| 🌜 暗色霓虹 | 始终使用「暗色霓虹 C 方案」——适合夜班、大屏监控台、会议室投屏 |
| 🖥 跟随系统 | 自动跟随操作系统配色偏好；切换 OS 浅/深时，页面会立即跟着变 |

> 选择会记住下次仍生效（写在浏览器本地存储 `sems_theme_mode`），不同电脑/浏览器互不影响。

### 2.2 操作步骤

1. 点击右上角主题按钮；
2. 下拉菜单中有 3 项：
   - **明色青绿**
   - **暗色霓虹**
   - **跟随系统**（菜单底部有分隔线，与前两项区分）
3. 单击任意一项即可立即切换，全页面颜色会平滑过渡。

### 2.3 三种模式的典型使用场景

| 场景 | 推荐模式 | 理由 |
|------|----------|------|
| 工厂车间电脑白天监控 | 明色青绿 | 背景明亮，状态标签易辨认 |
| 夜班工程师/洁净室监控大屏 | 暗色霓虹 | 低亮度，减少视觉疲劳和反光 |
| 笔记本/个人办公 | 跟随系统 | 系统定时切换浅深，无需手动改 |
| 投屏给客户演示 | 明色青绿（一般） | 投影常见偏暗，明色更清晰 |

### 2.4 常见疑问

| 疑问 | 回答 |
|------|------|
| 为什么暗模式下状态标签不再"亮瞎眼"？ | 系统对 `el-tag 实心/空心/浅色`、`按钮`、`头像`、`下拉菜单`、`消息气泡` 等组件做过专门的暗色补丁，背景亮度压到更低，同时保持 RUN/PM/IDLE/DOWN 语义颜色可读 |
| 跟随系统不生效？ | 请确认操作系统浅/深确实切换了（Win：设置→个性化→颜色→"选择模式"；macOS：系统设置→外观）。浏览器如果是远程桌面/虚拟机，可能需要重新打开浏览器 |
| 换了台电脑为什么主题又变了？ | 主题偏好保存在当前浏览器，不跟账号走；用新电脑重新选一次即可 |
| 想自定义颜色？ | 联系管理员/开发：可修改 `frontend/src/styles/theme.css` 中的 CSS 变量来替换主色和背景色（见 README 的「🎨 UI 主题」章节） |

## 3. 分级菜单（8 大分组）与角色看板

### 3.1 8 大分组菜单

SEMS 将所有功能划分为 8 个分组，左侧菜单采用**折叠式分级导航**，不再是一页平铺。点击分组标题可展开 / 收起该组下的所有子菜单。

> ⚠️ **系统配置永远在最末一组**：无论增删什么模块，「系统配置」始终排在菜单最后一组（最下方），便于管理员养成肌肉记忆。

| 序号 | 分组名称 | 包含模块（典型） | 典型使用角色 |
|------|----------|------------------|-------------|
| ① | 设备管理 | 设备台账、设备全生命周期、润滑管理 | 工程师、管理员 |
| ② | 日常运维 | 工单管理、PM 维护计划、点检巡检 | 工程师、操作员 |
| ③ | 工艺文控 | 工艺文件、表单模板管理 | 工艺员、QA、管理员 |
| ④ | 品管工具 | 8D 报告、FMEA | QA、工程师 |
| ⑤ | 合规安全 | 安全检查、环境核查 | QA、安全员、工程师 |
| ⑥ | 数据价值 | 故障知识库、设备成本 LCC、OEE 分析 | 工程师、管理员 |
| ⑦ | 人员资产 | 人员管理、资产管理 | 管理员、人事/资产岗 |
| ⑧ | **系统配置** | 用户管理、角色权限、备份、IP 白名单、系统设置（**永远在最末**） | 仅管理员可见 |

### 3.2 角色定制看板

不同角色登录后，**看板总览页展示的卡片组合与排序**会针对该角色日常工作重点自动适配：

| 角色 | 看板卡片（按优先级排序） |
|------|-------------------------|
| **管理员 admin** | DOWN 机数 / 超时预警 → 概览 → 工单 SLA 达成率 → 文控复审告警 → 8D 报告进度 → 知识库本月新增 → 低库存备件 → 安全检查到期 → 系统健康状态 |
| **工程师 engineer** | DOWN 机数 / 超时预警 → 我的工单 → 待验证工单 → 到期 PM → 到期点检 → 8D 报告进行中 → 相似故障知识推荐 |
| **工艺员 process_engineer** | DOWN 机数 → 工艺文件复审告警 → 表单审核待办 → 作业记录待提交 → 工艺验证设备 → 知识库工艺类条目 |
| **QA 审核员 qa** | 文控审核中 → 复审到期告警 → 附加修正审批 → 8D 报告（进行中/已关闭）→ 安全检查到期 → 表单审核锁定清单 |
| **操作员 operator** | 设备状态总览 → 我的工单 → 今日点检任务 → 润滑到期提醒 → 常用设备快速入口 |
| **查看者 viewer** | 设备状态总览 → 知识条目浏览 → 只读统计（OEE/成本概览等） |

> 看板卡片可通过顶栏「排序/显示」按钮自定义显示哪些卡片，调整后的排序保存在本地 `localStorage.sems_dashboard_layout`。

## 4. 看板总览

登录后默认进入看板总览页面。看板的配色会自动跟随您所选的主题（明色青绿 / 暗色霓虹 / 跟随系统）。

### 页面内容

- **顶部 KPI 卡片**：显示当前 **DOWN 机数**、**PM 进行中**、**⚠ 超时** 等核心指标；暗色霓虹模式下 KPI 卡片为暗底 + 同色系描边 + 彩色文字，避免亮反白。
- **设备实时状态表**：每台设备的当前状态、状态持续时长、最近变更原因和操作人、变更时间。
  - 状态标签（RUN / PM / IDLE / DOWN / ENGINEERING）为**语义色 + 细描边**；在暗色霓虹模式下背景亮度更低，夜班久看不累。
  - 操作人标签（OFF / PRODUCTION / ENG / OTHER）使用空心标签，不抢视觉重点。
- **筛选**：可按状态、厂区、区域、设备名/编号筛选。

### 常见操作

| 操作 | 说明 |
|------|------|
| 查看设备详情 | 点击设备行可跳转到设备档案页 |
| 筛选设备 | 使用顶部下拉框和搜索框 |
| 切换主题 | 右上角顶栏按钮（🌞/🌜/🖥） |

## 5. 设备台账

路径：菜单 → 设备台账

### 4.1 查看设备列表

- 设备列表显示所有设备的编号、名称、厂区、区域、状态等。
- 可按厂区、区域、状态筛选。

### 4.2 查看设备档案

点击设备行或"查看"按钮进入设备档案页，包含：
- **基本信息**：设备编号、名称、型号、厂区、区域、资产编号等。
- **状态历史**：设备状态变更记录（时间、从→到、原因、操作人）。
- **附件管理**：上传/下载设备相关文件（说明书、图纸等）。
- **关联备件**：该设备的易损件清单。

### 4.3 编辑设备信息

有 `equipment.write` 权限的角色（admin、engineer）可编辑设备信息。

## 6. 设备状态切换与工单触发

### 5.1 切换设备状态

在设备台账或设备档案页面，**右上角有状态切换按钮**：

1. 点击状态切换按钮。
2. 选择目标状态：
   - `RUN` — 运行
   - `IDLE` — 待机
   - `DOWN` — 故障停机
   - `PM` — 维护中
   - `ENGINEERING` — 工程调试
   - `PROCESS_VALIDATION` — 工艺验证
   - `OTHER` — 其他（需输入说明）
   - `OFFLINE` — 离线
3. 填写变更原因（选填）。
4. 确认提交。

> 所有角色（admin、engineer、operator）都可以切换设备状态。

### 5.2 DOWN 状态自动触发工单

当设备状态切换为 **DOWN** 时：
1. 系统自动创建一条 `REPAIR` 类型的工单。
2. 工单包含设备信息、故障现象（变更原因）、紧急度。
3. 工单自动分配给相关人员进行维修。

## 7. 工单管理

路径：菜单 → 工单管理

### 6.1 查看工单列表

- 工单列表显示编号、设备、类型（PM/REPAIR）、标题、状态、紧急度、创建时间。
- **持续时长**：显示工单从创建到关闭（或到当前时间）的总时长，方便跟踪维修进度。
- **关键词检索**：在搜索框输入关键词（如"漏真空"、"传感器"），可命中工单标题、描述、故障现象中的匹配内容。

### 6.2 创建工单

1. 点击"新建工单"按钮。
2. 选择设备、填写工单标题和描述。
3. 设置紧急度（LOW / NORMAL / HIGH / URGENT）。
4. 提交。

### 6.3 工单详情

点击工单行进入详情页，可查看/操作：
- **基本信息**：设备、类型、状态、紧急度、持续时长。
- **故障分析（5Why）**：记录根本原因分析。
- **备件领用**：记录维修使用的备件。
- **状态流转**：待处理 → 处理中 → 待验证 → 已关闭 / 已取消。

### 6.4 工单状态说明

| 状态 | 含义 |
|------|------|
| OPEN | 新建/待处理 |
| IN_PROGRESS | 处理中 |
| PENDING_VERIFICATION | 待验证 |
| CLOSED | 已关闭 |
| CANCELLED | 已取消 |

## 8. PM 维护计划

路径：菜单 → PM 维护计划

### 7.1 创建 PM 计划

1. 点击"新建计划"。
2. 选择设备、设置周期（周/双周/月/季度/半年/年）。
3. 填写维护内容描述。
4. 设置开始日期。

### 7.2 生成到期 PM 工单

- 系统会自动检测到期的 PM 计划。
- 有 `pm_plan.generate_due` 权限的角色可点击"生成到期PM工单"按钮，批量创建 PM 类型工单。

## 11. 工艺文件管理

路径：菜单 → 工艺文件

### 10.1 两大分类

| 分类 | 说明 | 典型文件 |
|------|------|----------|
| **指导性文件** | 重版本管理，旧版自动归档 | Recipe 配方、流程图、规格书、作业指导书 |
| **作业记录文件** | 按批号/班次/生产日期归档 | 批次记录、参数记录、检验记录、交接班记录 |

### 10.2 上传文件

1. 选择"指导性文件"或"作业记录文件"Tab。
2. 点击"上传"按钮。
3. 选择关联机台。
4. 选择文件（支持 PDF/Word/Excel/PPT/图片/压缩包，最大 50MB）。
5. 填写文件名称、类型、版本号/批号/班次/生产日期等。
6. 确认上传。

### 10.3 版本管理

- **查看版本历史**：点击"版本"按钮，查看同一文档的所有版本。
- **上传新版本**：点击"新版本"按钮，上传新文件作为新版本，旧版自动归档。
- **状态流转**：草稿 → 生效 → 作废（单向流转）。发布新版本生效时，同文档的其他"生效"版本自动转为"作废"。

### 10.4 结构化表单记录

作业记录除了传统的 PDF/Excel 附件上传外，还支持**结构化电子表单**：

- 在列表中，"表单来源"列显示`结构化填写`的记录即为电子表单记录。
- 点击"填写"按钮可编辑记录内容。
- 点击"查看填写"可只读查看已填写的值。
- 点击"导出JSON / 导出CSV"可导出结构化数据。

> 详细操作见下一章。

## 12. 表单模板与电子表单填写

### 11.1 概述

传统模式下，作业记录通过上传 PDF/Excel 附件归档。本功能允许：

- **管理员**在"表单模板管理"页面定义模板（字段、类型、选项等）。
- **操作员**在"工艺文件→作业记录"页面选模板生成电子表单并填写。
- 数据结构化存储，支持导出 JSON/CSV。

### 11.2 管理员操作：创建表单模板

路径：菜单 → 表单模板管理（仅管理员可见）

#### 第 1 步：新建模板

1. 点击"新建模板"按钮。
2. 填写基本信息：
   - **模板名称**（必填）：如"ET-200 薄膜沉积工艺参数记录表"
   - **模板编码**（选填）：如"PROC-PARAM-ET200"，建议英文大写
   - **分类**：选"作业记录类(record)"
   - **适用机台**：选择特定设备或留空（留空=通用模板）
   - **模板说明**：填写说明文字
   - **启用状态**：默认启用
3. 点击保存。

#### 第 2 步：定义字段

在模板编辑对话框中，通过顶部工具栏添加字段：

| 字段类型 | 适用场景 | 可选配置 |
|----------|----------|----------|
| 文本 | 姓名、编号等短文本 | 占位提示、默认值 |
| 多行文本 | 异常描述、备注等长文本 | 占位提示、默认值 |
| 数字 | 温度、压力、时间等数值 | 单位、最小值、最大值、默认值 |
| 下拉 | 班次、工序等固定选项 | 选项列表（格式：标签=值，用分号分隔） |
| 单选 | 合格/不合格等二选一 | 选项列表 |
| 日期 | 生产日期 | 占位提示 |
| 日期时间 | 开机时间、故障发生时间 | 占位提示 |
| 时间 | 交接时间 | 占位提示 |
| 是/否 | 是否完成清洁等布尔值 | 默认值 |

**字段配置要点**：
- **字段 Key**：英文小写+下划线，模板内唯一（如 `chamber_temp`、`operator_name`）
- **显示名**：中文显示名称（如"腔体温度"、"操作员"）
- **必填**：勾选后该字段为必填
- **排序**：通过上下箭头调整字段显示顺序

#### 第 3 步：上传参考模板文件（可选）

1. 在模板列表中找到刚创建的模板。
2. 点击"上传参考"按钮。

> 填写表单时，用户可点击"下载参考模板对照"下载此文件。

#### 第 4 步：启用模板

确认模板状态为"启用"。如需暂停使用，点击"停用"。

## 13. 文控系统（审批/修订/分发/审核）

路径：菜单 → 工艺文件

文控系统基于工艺文件模块扩展，实现符合质量体系标准的文档控制。核心能力包括：三级电子签名审批链、修订记录、分发收回、PDF 水印受控章、表单审核锁定、附加修正、复审告警。

### 12.1 角色与权限

| 角色 | 可执行操作 |
|------|-----------|
| 管理员 (admin) | 全部操作（上传、提交审核、审核、批准、作废、修订、分发、表单审核、附加修正） |
| 工艺员 (process_engineer) | 上传/编辑文档、提交审核、查看全部版本 |
| QA审核员 (qa) | 审核、批准、作废、分发、表单审核、附加修正审批 |
| 操作员 (operator) | 仅查看生效版本、下载受控 PDF |

> **注意**：管理员需在「系统配置 → 用户管理」中创建 QA 角色的用户账号，分配给负责审核的 QA 人员。

### 12.2 文档审批流程

```
草稿 ──提交审核──→ 审核中 ──审核通过──→ ──批准生效──→ 生效
                    │                       │              │
                    │驳回                   │驳回           │作废
                    ↓                       ↓              ↓
                  草稿                    草稿          作废(终态)
```

#### 12.2.1 编制提交（工艺员/管理员）

1. 在工艺文件页面上传文档（状态为「草稿」）。
2. 在编辑对话框中填写**文档编号**（手动编辑，如 `SOP-EQ-001`）、文控分类（SOP/SIP/SPEC/FORM/RECORD/EXTERN）、复审周期（月）。
3. 点击「提交审核」按钮。
4. 在弹出的审批对话框中：
   - 确认签署阶段显示为「编制提交」
   - 填写签署意见（可选）
   - 输入**登录密码**进行二次校验
   - 点击「确认签署」
5. 文档状态变为「审核中」。

> 如需驳回退回草稿，点击「驳回」并必须填写原因。

#### 12.2.2 审核（QA/管理员）

1. 在工艺文件页面找到状态为「审核中」的文档。
2. 点击「审核」按钮。
3. 在审批对话框中输入密码 + 意见 → 确认签署。
4. 审核通过后可继续批准；驳回则退回草稿。

> 同一文档不能重复审核。

#### 12.2.3 批准生效（QA/管理员）

1. 审核通过后，点击「批准」按钮。
2. 输入密码 + 意见 → 确认签署。
3. 文档状态变为「生效」，系统自动：
   - 写入生效日期（`effective_date`）
   - 按复审周期计算下次复审日期（`next_review_date` = 生效日期 + N 个月）
   - 同组旧生效版自动作废

### 12.3 修订记录

1. 点击文档行的「修订」按钮。
2. 在修订记录对话框中可查看历史修订记录。
3. 点击「新建修订」：
   - 填写变更原因、变更摘要
   - 可添加明细项（字段名 / 原值 / 新值）
4. 保存后记录显示在修订时间线中。

### 12.4 分发与收回

1. 点击文档行的「分发」按钮。
2. 在分发记录对话框中可查看历史分发记录。
3. 点击「新建分发」：
   - 选择分发对象类型（用户 / 部门）
   - 填写分发份数、备注
4. 可对已分发记录执行「收回」操作，填写收回原因。

### 12.5 PDF 水印受控章

- 下载 PDF 文件时，系统自动在文件上加盖受控章：
  - 文档编号
  - 文档状态（草稿/审核中/生效/作废）
  - 下载人用户名
  - 下载日期时间
- 非 PDF 文件直接下载（不加水印）。

### 12.6 表单审核锁定

针对结构化表单记录（基于模板填写的电子表单）：

1. 表单填写提交后，QA/管理员可点击「文控审核」按钮。
2. 审核通过后表单状态变为「已审核」，**禁止原地修改**。
3. 如需修改已审核表单，必须走「附加修正」流程。

### 12.7 附加修正

1. 对已审核的表单记录，点击「附加修正」按钮。
2. 在对话框中：
   - 选择要修正的字段
   - 填写原值、修正值、修正原因
   - 输入密码二次校验
3. 提交后修正记录状态为 PENDING。
4. QA/管理员审批修正：PENDING → APPROVED。

### 12.8 复审告警

- 工艺文件列表中，状态列旁会显示红色 Badge：
  - 「即将到期」：下次复审日期在 30 天内
  - 「已过期」：下次复审日期已过
- 可据此安排文档复审或更新。

## 14. 品管工具（8D / FMEA）与 8D→知识库归档

路径：菜单 → 品管工具（④ 品管工具分组）

### 14.1 8D 报告

- 创建 8D 报告，按 D1 团队组建 → D2 问题定义 → D3 临时遏制措施 → D4 根本原因分析 → D5 永久纠正措施 → D6 实施与验证 → D7 预防再发 → D8 表彰与总结，8 个步骤完整填写。
- 可关联来源工单（`work_order_id`）。
- 报告状态：`DRAFT / IN_PROGRESS / CLOSED / REJECTED`。
- **已关闭（CLOSED）的 8D 报告**建议立即归档知识库（见下一节），让经验沉淀复用。

#### 操作流程

1. 点击「新建 8D 报告」按钮。
2. 选择关联设备（必填）、关联工单（可选）、填写报告编号、标题、问题描述（D0）。
3. 按 8 个步骤依次填写：D1 团队 / D2 问题定义 / D3 临时措施 / D4 根因 / D5 永久措施 / D6 效果验证 / D7 预防 / D8 表彰。
4. 状态改为「已关闭 (CLOSED)」后即可归档为知识条目。

### 14.2 8D → 故障知识库一键归档

8D 报告是**故障知识沉淀的最佳来源**——D2 已定义问题、D4 已分析根因、D5 已制定永久措施、D7 已制定预防策略，系统支持一键把 8D 报告的这些内容自动提取并归档为故障知识库条目，无需手动复制粘贴。

#### 两种归档方式

**方式 A：从 8D 报告列表直接归档（推荐）**
1. 在「品管工具 → 8D 报告」列表中找到已关闭的 8D 报告。
2. 点击「归档至知识库」按钮。
3. 确认或调整以下可选字段：
   - **标题**：默认 = 8D 报告标题，可覆盖
   - **故障分类**：机械/电气/工艺/软件/气动/其他
   - **标签**：留空则自动生成 `8D,{报告编号}`，例如 `8D,8D-2025-001`
4. 点击「归档」，系统自动：
   - D0（problem）+ D2（problem_desc）→ `symptom` 故障现象
   - D4（root_cause）→ `root_cause` 根因
   - D5（permanent）→ `solution` 处置措施
   - D7（prevent）→ `prevention` 预防措施
   - 记录 `source_d8_report_id` 溯源关联 + `source_work_order_id`（如 8D 关联了工单）

**方式 B：从故障知识库页面手动指定 8D 报告**
1. 进入菜单「数据价值 → 故障知识库」。
2. 点击「从 8D 报告归档」按钮。
3. 在下拉中选择 8D 报告（可按编号或标题筛选）。
4. 填可选分类/标签，点击「归档」。

> ⚠️ 归档会创建一条新的知识库条目，**不会修改或删除原始 8D 报告**。同一 8D 报告可在知识库里有多个条目（不推荐但不禁止，用于不同角度提炼）。

### 14.3 FMEA

- 创建 FMEA 分析表，记录失效模式、影响、严重度（S 1-10）、频度（O 1-10）、探测度（D 1-10）。
- 自动计算 RPN（风险优先数）= S × O × D，RPN > 100 的条目高亮提醒改进优先级。
- 支持按工序 / 设备 / 组件维度过滤。

## 15. 故障知识库（双路径归档 + 相似案例 + 复发追踪）

路径：菜单 → 数据价值 → 故障知识库

### 15.1 双路径归档来源

故障知识可通过两条路径自动沉淀，也可手动新建：

| 来源路径 | 自动填充内容 | 典型适用场景 |
|----------|------------|------------|
| **工单归档** | 工单 `description` → 现象 / `fault_category` → 分类 / `root_cause` → 根因 / `solution` → 处置 / `prevention` → 预防；记录 `source_work_order_id` | 日常维修工单关闭后，快速把处置经验入库 |
| **8D 报告归档** | D0+D2 → 现象 / D4 → 根因 / D5 → 处置 / D7 → 预防；记录 `source_d8_report_id` + 工单 ID | 8D 报告完成（CLOSED）后，把结构化分析成果沉淀 |
| **手动新建** | 自由填写所有字段 | 通用经验 / 历史案例手工整理录入 |

### 15.2 列表查询与统计

- **筛选**：按关键词（标题 / 现象 / 根因 / 处置全文模糊匹配）、故障分类、关联设备过滤。
- **统计行**：
  - 总条目数
  - 本月新增条目数
  - 复发次数合计（追踪同一根因是否反复出现）

### 15.3 查看详情与相似案例

点击知识条目的「查看详情」按钮：
- 完整展示标题 / 分类 / 设备 / 设备型号 / 现象 / 根因 / 处置 / 预防 / 标签 / **来源工单** / **来源8D报告** / 浏览次数 / 复发次数 / 创建人 / 时间。
- 浏览详情时 `views` 计数自动 +1。
- **相似案例推荐区**：自动基于「相同设备 + 相同故障分类」推荐同设备同分类的历史条目（按复发次数/浏览量倒序），其次退化为「同设备或同分类」。一眼看到以前处理过的类似故障怎么处置。

### 15.4 标记复发

当**同一根因**的故障在另一台设备 / 另一批次再次出现时：
1. 在知识条目列表找到对应的历史条目。
2. 点击「标记复发」按钮 → 二次确认。
3. 该条目 `recurrence_count` 自动 +1。
4. 标记复发后，管理人员可在看板和统计列表中一眼看出哪些根因反复出现、需要重点投入改进（如新增 PM 项、升级备件等级、调整工艺参数等）。

### 15.5 从工单归档（路径）

1. 进入「故障知识库」页面。
2. 点击「从工单归档」按钮。
3. 输入工单 ID。
4. 系统自动把工单信息（故障描述 / 分类 / 根因 / 处置 / 预防）填充为新条目；可再手动微调后保存。
