## 1. 登录与密码

### 1.1 登录

1. 浏览器打开系统地址（如 `http://localhost:5173` 开发环境或 `http://<服务器IP>:8080` 生产环境）。
2. 输入用户名和密码，点击登录。

### 1.2 首次登录强制改密

- 系统默认管理员账号为 `admin` / `admin123`。
- 首次登录时系统会**强制跳转到修改密码页面**。
- 密码要求：
  - 至少 **8** 位
  - 包含大写字母、小写字母、数字、特殊符号中的 **至少 3 类**
  - 不能使用常见弱密码（如 `12345678`、`password`）

### 1.3 忘记密码

联系管理员重置密码。管理员重置后，您的账号会被标记为"必须改密"，下次登录时需重新设置密码。

### 1.4 登录过期

- 访问令牌有效期为 **2 小时**，系统会在到期前 5 分钟自动续期。
- 如果长时间不操作导致登录过期，系统会跳回登录页。重新登录即可。
- **如果反复提示"登录已过期"**：请清除浏览器 localStorage（F12 → Application → Local Storage → 删除 `sems_` 前缀的条目），然后重新登录。

## 2. 看板总览

登录后默认进入看板总览页面。

### 页面内容

- **顶部统计卡片**：显示当前 RUN / IDLE / DOWN / PM 状态的设备数量，以及超时预警数。
- **设备实时状态表**：每台设备的当前状态、状态持续时长、最近变更原因和操作人、变更时间。
- **筛选**：可按状态、厂区、区域、设备名/编号筛选。

### 常见操作

| 操作 | 说明 |
|------|------|
| 查看设备详情 | 点击设备行可跳转到设备档案页 |
| 筛选设备 | 使用顶部下拉框和搜索框 |

## 3. 设备台账

路径：菜单 → 设备台账

### 3.1 查看设备列表

- 设备列表显示所有设备的编号、名称、厂区、区域、状态等。
- 可按厂区、区域、状态筛选。

### 3.2 查看设备档案

点击设备行或"查看"按钮进入设备档案页，包含：
- **基本信息**：设备编号、名称、型号、厂区、区域、资产编号等。
- **状态历史**：设备状态变更记录（时间、从→到、原因、操作人）。
- **附件管理**：上传/下载设备相关文件（说明书、图纸等）。
- **关联备件**：该设备的易损件清单。

### 3.3 编辑设备信息

有 `equipment.write` 权限的角色（admin、engineer）可编辑设备信息。

## 4. 设备状态切换与工单触发

### 4.1 切换设备状态

在设备台账或设备档案页面，**右上角有状态切换按钮**：

1. 点击状态切换按钮。
2. 选择目标状态：
   - `RUN` — 运行
   - `IDLE` — 待机
   - `DOWN` — 故障停机
   - `PM` — 维护中
   - `ENGINEERING` — 工程调试
   - `PROCESS_VALIDATION` — 工艺验证
   - `OTHER` — 其他（需输入说明）
   - `OFFLINE` — 离线
3. 填写变更原因（选填）。
4. 确认提交。

> 所有角色（admin、engineer、operator）都可以切换设备状态。

### 4.2 DOWN 状态自动触发工单

当设备状态切换为 **DOWN** 时：
1. 系统自动创建一条 `REPAIR` 类型的工单。
2. 工单包含设备信息、故障现象（变更原因）、紧急度。
3. 工单自动分配给相关人员进行维修。

## 5. 工单管理

路径：菜单 → 工单管理

### 5.1 查看工单列表

- 工单列表显示编号、设备、类型（PM/REPAIR）、标题、状态、紧急度、创建时间。
- **持续时长**：显示工单从创建到关闭（或到当前时间）的总时长，方便跟踪维修进度。
- **关键词检索**：在搜索框输入关键词（如"漏真空"、"传感器"），可命中工单标题、描述、故障现象中的匹配内容。

### 5.2 创建工单

1. 点击"新建工单"按钮。
2. 选择设备、填写工单标题和描述。
3. 设置紧急度（LOW / NORMAL / HIGH / URGENT）。
4. 提交。

### 5.3 工单详情

点击工单行进入详情页，可查看/操作：
- **基本信息**：设备、类型、状态、紧急度、持续时长。
- **故障分析（5Why）**：记录根本原因分析。
- **备件领用**：记录维修使用的备件。
- **状态流转**：待处理 → 处理中 → 待验证 → 已关闭 / 已取消。

### 5.4 工单状态说明

| 状态 | 含义 |
|------|------|
| OPEN | 新建/待处理 |
| IN_PROGRESS | 处理中 |
| PENDING_VERIFICATION | 待验证 |
| CLOSED | 已关闭 |
| CANCELLED | 已取消 |

## 6. PM 维护计划

路径：菜单 → PM 维护计划

### 6.1 创建 PM 计划

1. 点击"新建计划"。
2. 选择设备、设置周期（周/双周/月/季度/半年/年）。
3. 填写维护内容描述。
4. 设置开始日期。
5. 保存。

### 6.2 生成到期 PM 工单

- 系统会自动检测到期的 PM 计划。
- 有 `pm_plan.generate_due` 权限的角色可点击"生成到期PM工单"按钮，批量创建 PM 类型工单。

## 7. 点检巡检

路径：菜单 → 点检巡检

### 7.1 点检模板

2. 逐项填写检查结果。

### 8.1 备件列表

## 9. 工艺文件管理

路径：菜单 → 工艺文件

### 9.1 两大分类

| 分类 | 说明 | 典型文件 |
|------|------|----------|
| **指导性文件** | 重版本管理，旧版自动归档 | Recipe 配方、流程图、规格书、作业指导书 |
| **作业记录文件** | 按批号/班次/生产日期归档 | 批次记录、参数记录、检验记录、交接班记录 |

### 9.2 上传文件

1. 选择"指导性文件"或"作业记录文件"Tab。
2. 点击"上传"按钮。
3. 选择关联机台。
4. 选择文件（支持 PDF/Word/Excel/PPT/图片/压缩包，最大 50MB）。
5. 填写文件名称、类型、版本号/批号/班次/生产日期等。
6. 确认上传。

### 9.3 版本管理

- **查看版本历史**：点击"版本"按钮，查看同一文档的所有版本。
- **上传新版本**：点击"新版本"按钮，上传新文件作为新版本，旧版自动归档。
- **状态流转**：草稿 → 生效 → 作废（单向流转）。发布新版本生效时，同文档的其他"生效"版本自动转为"作废"。

### 9.4 结构化表单记录

作业记录除了传统的 PDF/Excel 附件上传外，还支持**结构化电子表单**：

- 在列表中，"表单来源"列显示`结构化填写`的记录即为电子表单记录。
- 点击"填写"按钮可编辑记录内容。
- 点击"查看填写"可只读查看已填写的值。
- 点击"导出JSON / 导出CSV"可导出结构化数据。

> 详细操作见下一章。

## 10. 表单模板与电子表单填写

### 10.1 概述

传统模式下，作业记录通过上传 PDF/Excel 附件归档。本功能允许：

- **管理员**在"表单模板管理"页面定义模板（字段、类型、选项等）。
- **操作员**在"工艺文件→作业记录"页面选模板生成电子表单并填写。
- 数据结构化存储，支持导出 JSON/CSV。

### 10.2 管理员操作：创建表单模板

路径：菜单 → 表单模板管理（仅管理员可见）

#### 第 1 步：新建模板

1. 点击"新建模板"按钮。
2. 填写基本信息：
   - **模板名称**（必填）：如"ET-200 薄膜沉积工艺参数记录表"
   - **模板编码**（选填）：如"PROC-PARAM-ET200"，建议英文大写
   - **分类**：选"作业记录类(record)"
   - **适用机台**：选择特定设备或留空（留空=通用模板）
   - **模板说明**：填写说明文字
   - **启用状态**：默认启用
3. 点击保存。

#### 第 2 步：定义字段

在模板编辑对话框中，通过顶部工具栏添加字段：

| 字段类型 | 适用场景 | 可选配置 |
|----------|----------|----------|
| 文本 | 姓名、编号等短文本 | 占位提示、默认值 |
| 多行文本 | 异常描述、备注等长文本 | 占位提示、默认值 |
| 数字 | 温度、压力、时间等数值 | 单位、最小值、最大值、默认值 |
| 下拉 | 班次、工序等固定选项 | 选项列表（格式：标签=值，用分号分隔） |
| 单选 | 合格/不合格等二选一 | 选项列表 |
| 日期 | 生产日期 | 占位提示 |
| 日期时间 | 开机时间、故障发生时间 | 占位提示 |
| 时间 | 交接时间 | 占位提示 |
| 是/否 | 是否完成清洁等布尔值 | 默认值 |

**字段配置要点**：
- **字段 Key**：英文小写+下划线，模板内唯一（如 `chamber_temp`、`operator_name`）
- **显示名**：中文显示名称（如"腔体温度"、"操作员"）
- **必填**：勾选后该字段为必填
- **排序**：通过上下箭头调整字段显示顺序

#### 第 3 步：上传参考模板文件（可选）

1. 在模板列表中找到刚创建的模板。
2. 点击"上传参考"按钮。
3. 选择空白模板文件（PDF/Excel/图片等），作为填写时的参考对照。

> 填写表单时，用户可点击"下载参考模板对照"下载此文件。

#### 第 4 步：启用模板

确认模板状态为"启用"。如需暂停使用，点击"停用"。

### 10.3 操作员操作：新建电子表单

路径：菜单 → 工艺文件 → "作业记录文件"Tab

#### 第 1 步：新建电子表单

1. 切换到"作业记录文件"Tab。
2. 点击页面右上角蓝色**"新建电子表单"**按钮。
3. 系统弹出"选择表单模板"对话框，显示所有启用中的作业记录模板。

#### 第 2 步：选择模板

- 查看模板列表，了解模板编码、名称、适用机台、字段数。
- 点击"选择"按钮，或双击模板行。

#### 第 3 步：填写表单

选择模板后，系统弹出"基于模板新建电子表单"对话框：

1. **填写元数据**：
   - 关联机台（必填）
   - 批次号（如 B20260807-01）
   - 班次（A/B/C）
   - 生产日期
   - 记录标题（留空自动生成）
   - 备注
2. **填写字段**：
   - 按模板定义的字段逐项填写。
   - 标有 `*` 的为必填字段。
   - 如模板上传了参考文件，可点击右上角"下载参考模板对照"。
3. **保存**：
   - 点击"保存草稿"：记录保存为草稿状态，可稍后继续编辑。
   - 点击"保存并提交"：记录直接变为已提交状态。

> 保存后，系统会自动在作业记录列表中创建一条关联的工艺文件条目。

### 10.4 编辑已有电子表单记录

1. 在作业记录列表中，找到"表单来源"列为`结构化填写`的记录。
2. 点击操作列的**"填写"**按钮。
3. 系统弹出"填写电子表单"对话框，显示当前记录的状态和已填写的值。
4. 修改字段值后：
   - **草稿状态**：可点击"保存草稿"或"提交"。
   - **已提交状态**：可点击"保存修改"修改字段值（状态保持已提交）。
   - **已作废状态**：不允许编辑。

### 10.5 查看与导出

| 操作 | 说明 |
|------|------|
| **查看填写** | 点击"查看填写"按钮，只读查看所有字段值和元数据 |
| **导出 JSON** | 点击"导出JSON"按钮，下载结构化 JSON 文件 |
| **导出 CSV** | 点击"导出CSV"按钮，下载 CSV 文件（可用 Excel 打开） |
| **下载附件** | 对于附件文件类型的记录，点击"下载"按钮下载原始文件 |

### 10.6 状态说明

| 状态 | 说明 | 可执行操作 |
|------|------|-----------|
| 草稿 | 新建但未提交 | 编辑、保存、提交、作废 |
| 已提交 | 已正式提交 | 编辑修改（保持已提交状态）、作废 |
| 已作废 | 已作废，不可用 | 仅查看 |

## 15. 系统配置

路径：菜单 → 系统配置（仅管理员）

### 15.1 用户管理

- 创建/编辑/删除用户。
- 分配角色（admin / engineer / process_engineer / operator / viewer）。
- 重置密码（重置后用户需改密）。
- 解锁被锁定的账号。

### 15.2 角色权限

- 查看角色 × 功能权限矩阵。
- 可逐项调整各角色对各功能的权限。

### 15.3 系统备份

- **手动备份**：一键打包数据库 + 上传附件。
- **加密备份**：设置加密密码后，备份文件自动 AES-256 加密。
- **异地副本**：设置第二备份目录后，备份自动复制到异地（NAS/SMB/U盘）。
- **定时备份计划**：设置 cron 表达式，系统按计划自动备份。
- **恢复备份**：上传备份文件恢复数据。
- **备份安全性状态**：检查加密和异地副本是否已配置。

### 15.4 IP 白名单

- 限制可访问系统的 IP 地址范围。
- 适合仅允许特定电脑访问的场景。

### 15.5 系统设置

- 查看/修改环境变量配置。
- 重启后端服务。
